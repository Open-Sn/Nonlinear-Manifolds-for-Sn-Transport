# 2-D reproduction workflow

## Overview

The two-dimensional reproduction is organized as three sequential stages. The
current repository contains the recovered OpenSn full-order inputs and the
validated preprocessing/POD workflow. The ROM execution stage is reserved for
the remaining paper reproduction work and will be populated separately.

## Workflow

```text
01_run_opensn
      ↓
OpenSn angular-flux snapshots + steady state
      ↓
02_prepare_for_rom
      ↓
mass matrices + centered snapshot matrix + POD
      ↓
03_execute_rom
```

## Stage 1: OpenSn full-order calculation

[`01_run_opensn/`](01_run_opensn/) contains the transient and steady-reference
OpenSn inputs, mesh, and fissile cross-section file. It produces the angular
flux used by Stage 2 and scalar-flux output for diagnostics.

See the [Stage 1 instructions](01_run_opensn/README.md).

## Stage 2: Preparation for ROM

[`02_prepare_for_rom/`](02_prepare_for_rom/) reconstructs the spatial DG mass
matrices and direction-independent full-order operators, builds the
steady-centered X1000 angular snapshot matrix, and computes and validates the
mass-weighted K80 POD products.

See the [Stage 2 instructions](02_prepare_for_rom/README.md).

## Stage 3: ROM execution

[`03_execute_rom/`](03_execute_rom/) is currently reserved for the ROM
reproduction workflow. It intentionally contains no ROM implementation yet.

## Large scientific data

Large OpenSn VTUs and archives, the canonical X1000 matrix, and generated POD
products are intentionally not stored in Git. They may be generated by Stages
1 and 2 or obtained from the separately archived scientific dataset.
